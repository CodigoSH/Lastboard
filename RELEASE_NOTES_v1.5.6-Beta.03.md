### Accessibility
- Modal dialogs now trap keyboard focus, close with **Escape**, and return focus to the control that opened them
- Icon-only buttons (dialog close, mobile visibility toggle) now expose proper screen-reader labels
- The **Add** menu and the avatar / dashboard-background pickers are fully operable with the keyboard (Tab + Enter/Space)

### Fixed
- Dismissing a confirmation or password dialog with **Escape** no longer leaves the pending action hanging
