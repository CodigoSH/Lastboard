**The same build as Beta.06, to try the update that keeps the server answering**

This is a beta of 1.11.0, offered only to installations on the beta channel. It carries exactly what Beta.06 did: see its notes for everything in this beta series.

### Changed
- **Nothing in the product.** This beta exists so that an installation already on Beta.06 has a newer version to update to from the button. That update is the first made by the new updater: the new version is tried before it is installed, the database is copied first, and the server restarts into it without closing its port, so a reverse proxy or tunnel in front keeps answering.
