# Clock Widget

The Clock widget displays the current time and date in a highly configurable format on your dashboard.

## Description

A clean, responsive analog/digital clock that can show local time or time from a specific timezone. It automatically scales to fit its container using container queries.

![Clock Widget](../assets/clock.png)

## Configuration Options

| Option | Default | Description |
| :--- | :--- | :--- |
| **Timezone** | Local | The timezone to display (e.g., `America/New_York`), or `local` for the browser's time. |
| **12/24 Hour Format** | 24 Hour | Toggle between 12-hour (AM/PM) and 24-hour display. |
| **Show Date** | Enabled | Display the current date beneath the time. |
| **Show Seconds** | Disabled | Display seconds in the time readout. |
