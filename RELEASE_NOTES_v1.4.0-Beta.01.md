# Release: v1.4.0-Beta.01

### ✨ Features
- **Personalized Dashboard Backgrounds**: Add your own images to the dashboard with per-user persistence.
- **Auto-Optimization**: Background images are automatically resized for performance.
- **Global Unit System**: Choose between Metric and Imperial units for all widgets in one place.
- **Clock Location**: Display city names and search for locations directly in the Clock widget.
- **Docker v29 Support**: Improved compatibility by removing hardcoded API versions.
- **Security Guardrail**: Prevents accidental stopping of the Lastboard Agent from the UI.

### 🐛 Bug Fixes
- Fix for Docker API routing and container status flickering.
- Resolved unit serialization issues in Weather and Telemetry.
- Fixed UI layout issues and documentation formatting.

### 🛠️ Refactors & Performance
- Optimized Telemetry polling via WebSocket.
- Unified widget aesthetics and glassmorphism effects.
- Comprehensive documentation overhaul.
